# Исходные спецификации и планы

Документы от 28.09.2026, по которым делались первые разделы: идентификационный номер, боковое меню и номер паспорта.
Это история решений, а не описание текущего поведения: после них добавлены ещё двадцать с лишним разделов, а часть
решений пересмотрена — например, ID-карта, которую спецификация оставляла вне рамок, теперь поддерживается.
Актуальные правила и источники — в [README](../../README.md#справочник-форматов).

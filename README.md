# by-data-tools

Валидация и генерация тестовых данных Республики Беларусь. Работает целиком в браузере:
введённые данные никуда не отправляются и не сохраняются.

**Открыть:** https://aquahitt.github.io/by-data-tools/

## Разделы

Разделы собраны в левом меню по категориям. Адрес раздела можно сохранить или отправить:
`#/<раздел>`, формат — параметром `?format=`.

| Категория | Раздел | Адрес |
|---|---|---|
| Документы | Идентификационный номер | `#/personal-number` |
| Документы | Паспорт, ID-карта, ВНЖ | `#/passport-number` |
| Люди | Тестовая персона | `#/persona` |
| Люди | ФИО латиницей | `#/name` |
| Организации | УНП, ОКПО, ОКЭД | `#/unp`, `#/okpo`, `#/oked` |
| Финансы | IBAN, BIC банка, банковская карта | `#/iban`, `#/bic`, `#/card` |
| Транспорт | Номерной знак, VIN | `#/plate`, `#/vin` |
| Адреса и недвижимость | Почтовый индекс, СОАТО, кадастровый номер участка | `#/postal`, `#/soato`, `#/cadastral` |
| Контакты | Телефон, email, IMEI | `#/phone`, `#/email`, `#/imei` |

## Идентификационный номер паспорта

Проверка, разбор и генерация (случайно или по заданным полям) в двух форматах —
формат выбирается переключателем:

- **2012+** — по [постановлению МВД РБ № 345 от 18.10.2011](https://mvd.gov.by/uploads/dgim/r345.pdf):
  `7xxxxxx A NNN PB C`, все правила обязательны.
- **До 2012** — пол и век, дата рождения, регион, порядковый номер, статус. Официально не описан;
  структура и коды — по данным [АиФ](https://aif.by/dontknows/kak_rasshifrovat_lichnyy_nomer_pasporta)
  и [onliner.by](https://forum.onliner.by/viewtopic.php?t=895870&start=160). Несовпадение контрольной
  цифры с формулой 7-3-1 показывается как предупреждение, а не ошибка. Случайные даты рождения генерируются с 1900 года,
  поэтому номера XIX века (первая цифра 1 или 2) получаются только из заданной даты.

Контрольная цифра: первые 13 символов, веса `7-3-1`, `A=10 … Z=35`, сумма по модулю 10.

## Паспорт, ID-карта, ВНЖ

Серия (2 латинские буквы) и номер (7 цифр). Четыре формата:

- **Образца 1996 г.** — серия по органу выдачи (`AB`, `BM`, `HB`, `KH`, `MP`, `MC`, `KB`, `PP`, `SP`, `DP`);
  серия не из списка — предупреждение, а не ошибка.
- **Биометрический (с 2021)** — серии бланков официально не опубликованы
  ([постановление Совмина № 297](https://etalonline.by/document/?regnum=c22100297) задаёт только формат),
  принимается любая пара латинских букв; `DP` — дипломатический.
- **ID-карта (с 2021)** — тот же вид номера по вторичным источникам; серии не опубликованы.
- **Вид на жительство** — «семизначный номер с серией из двух букв» (постановление Совмина № 1740 от 18.11.2008,
  бланк образца 2008 г.); формат номера биометрического вида на жительство не опубликован.

В разборе и при генерации показывается номер документа из машиночитаемой зоны с контрольной цифрой
(ICAO 9303, веса `7-3-1`).

## УНП

Учётный номер плательщика по [постановлению МНС № 127 от 31.12.2003](https://pravo.by/pdf/2004-38/2004-38(010-043).pdf)
(глава 3, приложения 2–3): 9 знаков — код области, порядковый номер, контрольная цифра
(веса `29 23 19 17 13 7 5 3`, остаток от деления на 11; остаток 10 — такой УНП не выдаётся). Два формата:

- **Организация** — девять цифр, первая `1`–`7` (область).
- **Физлицо / ИП** — буква области (`A B C E H K M`), буква вместо первой цифры порядкового номера
  (`0→A 1→B 2→C 3→E 4→H 5→K 6→M 7→O 8→P 9→T`), шесть цифр и контрольная цифра.

В примере постановления для физлица (`МА1953681`) сумма посчитана с ошибкой; инструмент следует формуле
(`MA1953684`), как и [python-stdnum](https://github.com/arthurdejong/python-stdnum/blob/master/stdnum/by/unp.py).
Префикс «УНП» или «UNP» при вводе допускается.

## IBAN / номер счёта

Номер счёта по структуре IBAN (постановление Правления НБРБ № 440 от 27.07.2015, действует с 04.07.2017),
28 символов: `BY`, две контрольные цифры (ISO 13616, mod 97), код банка — первые четыре символа BIC,
балансовый счёт (План счетов, [постановление НБРБ № 506](https://www.nbrb.by/legislation/documents/pp_506_137.pdf)),
16 знаков номера счёта в банке.

Банки — по [справочнику BIC НБРБ](https://www.nbrb.by/payment/bic) на 28.09.2026; код не из справочника —
предупреждение, а не ошибка. Расшифровываются распространённые балансовые счета клиентов (3011–3015, 3034,
3401–3405, 3411–3415). Префикс «IBAN» при вводе допускается; для IBAN другой страны разбираются только
страна и контрольные цифры.

## Телефон

`+375` и 9 цифр национального номера (план нумерации — постановление Совмина № 787 от 22.06.2006; коды — по
[сводке плана нумерации](https://ru.wikipedia.org/wiki/Телефонный_план_нумерации_Беларуси) и правилам набора
операторов). Контрольной цифры нет — проверяются формат и коды. Ввод: `+375 (29) 123-45-67`, `8 029 …`, `0 29 …`
или 9 цифр. Два формата:

- **Мобильный** — коды `25` life:), `29` A1 / МТС (по первой цифре абонентского номера: 1/3/6/9 — A1,
  2/5/7/8 — МТС, 0 и 4 — «оператор не определён»), `33` МТС, `44` A1.
- **Стационарный** — зоны `15` Гродненская, `16` Брестская, `17` г. Минск и Минская, `21` Витебская,
  `22` Могилёвская, `23` Гомельская; областные центры расшифровываются, районные коды — нет: такие номера показываются без разбивки на код и номер.

Первая цифра абонентского номера в генераторе (для городов кроме Минска — 2–9) — выбор инструмента,
а не опубликованное правило; проверка её не ограничивает.

## Тестовая персона

Набор согласованных данных для одного или до 100 человек: ФИО по-русски и по-белорусски, латиница по ICAO
из белорусской формы, пол и дата рождения (18–75 лет) — те же, что закодированы в идентификационном номере (формат до 2012 г.); буква региона
этого номера определяет серию паспорта образца 1996 г., область и почтовый индекс. Телефон, IBAN (счёт 3014 — физлицо),
карта (БЕЛКАРТ, Visa или Mastercard, номер банком не выпущен), email на резервном домене `example.com`.
Копируется в JSON или CSV (разделитель `;`, как ожидает Excel с русскими региональными настройками).

## ФИО латиницей

Показывает два написания, потому что источники расходятся в том, какое применяется по умолчанию:

- **Инструкция МВД № 288 от 09.10.2008** — таблица на [сайте МИД](https://france.mfa.gov.by/be/consular_issues/passport/trans/):
  `Г → G`, `Й → J`, `Ў → W`; в белорусском написании `Е Ё Ю Я` после согласной — `IE IO IU IA`, в начале слова,
  после гласной и `Ў` — `JE JO JU JA`, после `Ь`, `Ъ` и апострофа — `J` + гласная. Пример МИД «Лябецкая – Liabetskaja»
  противоречит его же правилу для `Е`; инструмент следует правилу.
- **ICAO 9303, часть 3** — `Й → I`, `Ъ → IE`, `Ю → IU`, `Я → IA`, `Ў → U`, для белорусского написания `Г → H`:
  так написаны имена в выданных паспортах (`SIARHEI`, `ALIAKSANDR`, `HANNA`).

Язык определяется по буквам: `І`, `Ў` и апостроф — белорусское написание, `И`, `Щ`, `Ъ` — русское; смешение — ошибка.
Если отличительных букв нет («Павел Жук»), показываются оба прочтения — там, где латиница у них различается.
Разбор даёт ФИО и на другом языке — RU и BY. Имена переводятся, а не транслитерируются (Сергей — Сяргей,
Елена — Алена), поэтому перевод идёт по словарю распространённых имён, отчеств и фамилий (около 45 мужских
и 42 женских имени, 48 фамилий); слова не из словаря остаются как есть и перечисляются отдельно. Для русского ФИО,
переведённого целиком, показывается и латиница из белорусской формы — как в паспорте.
Генератор выдаёт одного человека сразу в нескольких вариантах: RU и BY (ФИО полностью) и латиницей EN по ICAO
и по Инструкции № 288 — из белорусской формы, как в документах; отчество латиницей не пишется. Словари имён
и фамилий небольшие, выбраны инструментом.

## ОКПО

Официального описания нет. 8 цифр, восьмая — контрольная по правилу российского ОКПО (веса 1…7 по модулю 11,
при 10 — веса 3…9, при повторном 10 — 0); ему соответствуют все проверенные реальные коды (34 из 34). В 12-значной
записи девятая цифра — код области (как в СОАТО), последние три — подразделение, `000` — головная организация.

## ОКЭД

ОКРБ 005-2011 ([Белстат](https://www.belstat.gov.by/klassifikatory/), изменение № 7 действует с 01.01.2026):
5 цифр — раздел, группа, класс, подкласс. Проверяется существование раздела и определяется секция `A`–`U`;
классификатор опубликован только в PDF, поэтому существование подкласса не проверяется.

## BIC банка

ISO 9362 (постановление Правления НБРБ № 472 от 07.08.2015): 4 буквы банка, страна, 2 знака местонахождения,
необязательно 3 знака филиала (`XXX` — головной офис). Банк сверяется со [справочником НБРБ](https://www.nbrb.by/payment/bic)
на 28.09.2026 — тем же, что и для IBAN; иностранный банк, банк не из справочника или другое местонахождение — предупреждения.

## Банковская карта

Номер 12–19 цифр, контрольная цифра по алгоритму Луна (ISO/IEC 7812). Платёжная система — по диапазонам
([Payment card number](https://en.wikipedia.org/wiki/Payment_card_number)); БЕЛКАРТ — `9112`, 16 цифр
([Банк БелВЭБ](https://www.belveb.by/terms/nomer-bankovskoj-karty/)). У UnionPay несовпадение по Луна — предупреждение.
Узнаются опубликованные тестовые карты bePaid и Assist Belarus. Генератор (БЕЛКАРТ, Visa, Mastercard, Мир, можно
задать начало номера) даёт номера, не выпущенные банками.

## Номерной знак

СТБ 914-99 с изменениями 1–8: только буквы, одинаковые в кириллице и латинице — `А В Е І К М Н О Р С Т Х`
(вводить можно на любой раскладке); код региона `1`–`7`, `8` — резервный код Минска (с марта 2025,
[onliner.by](https://auto.onliner.by/2025/02/28/v-minske-budut-ispolzovat-gosnomera-s-regionom-nomer-8)),
`0` — Вооружённые силы, погранкомитет, внутренние войска (на таких знаках допустимы и другие кириллические буквы,
кроме `Д Ё Й Ц Щ`). Форматы: легковой `1234 AB-7` (тип 1), грузовой и автобус `AB 1234-7` (тип 2), прицеп
`A 1234 B-7` (тип 5), электромобиль `E123 AB-7` (с 01.07.2020, запись — по вторичным источникам), транзитный
`7 AB T 1234` (тип 12), такси `7 TAX 1234` (тип 13). Двухстрочные знаки мотоциклов, тракторов и прицепов
несут ту же запись, что типы 1 и 2. Дипломатические знаки не поддерживаются: их формат не удалось подтвердить.

## VIN

ISO 3779 и ТР ТС 018/2011 (приложение 7): 17 знаков без `I O Q`. Контрольный знак (позиция 9, веса
`8 7 6 5 4 3 2 10 0 9 8 7 6 5 4 3 2`, остаток 10 — `X`) обязателен только в США и Канаде — несовпадение
показывается как предупреждение. Разбор: WMI (Беларусь — `Y3`–`Y5`; `Y3M` МАЗ, `Y3J` Белкоммунмаш, `Y4F`, `Y4K` БелДжи),
модельный год (оба года 30-летнего цикла), завод, порядковый номер. Генератор считает контрольный знак.

## Почтовый индекс

6 цифр, начинаются с `2`. Область — по первым трём цифрам: `210–211` Витебская, `212–213` Могилёвская, `220` Минск,
`222–223` Минская, `224–225` Брестская, `230–231` Гродненская, `246–247` Гомельская (сводки индексов 1001pochta.ru,
b-info.by; справочник Белпочты в открытом виде не опубликован). Существование индекса не проверяется.

## СОАТО

ОКРБ 003-2017 (постановление Госстандарта № 17 от 06.03.2017): 10 цифр, первая — область (`1` Брестская, `2` Витебская,
`3` Гомельская, `4` Гродненская, `5` г. Минск, `6` Минская, `7` Могилёвская). Классификатор выдаётся НКА по запросу,
поэтому существование объекта не проверяется; значение позиций 2 (`2` район, `4` город областного подчинения) и 5
(`5` город или посёлок, `8` сельсовет) выведено из реальных кодов.

## Кадастровый номер участка

Постановление Комитета по земельным ресурсам № 14 от 08.04.2004: 18 цифр — СОАТО (1–10), кадастровый квартал `01`–`99`
(11–12), номер участка в квартале (13–18). Контрольной цифры нет.

## Email

Практическая проверка по RFC 5321/5322 (без адресов в кавычках и IP-адресов): имя до 64 символов, домен из частей
до 63 символов, зона не короче двух букв — `.by` и кириллическая `.бел` принимаются. Генератор по умолчанию берёт
резервные домены (`example.com`, `example.org`, `.test`), письма на которые никому не доставляются.

## IMEI

3GPP TS 23.003: IMEI — 15 цифр (TAC, серийный номер, контрольная цифра по Луна); IMEISV — 16 цифр
(TAC, серийный номер, версия ПО), без контрольной цифры.

## Не добавлено

Номер водительского удостоверения и свидетельства о регистрации ТС: их формат не удалось подтвердить ни по одному
надёжному источнику.

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173/by-data-tools/
npm test
npm run build
```

Новый раздел — модуль формата в `src/formats/` (реализует `FormatModule` из `src/core/types.ts`)
и запись в реестре `src/tools/index.ts`; меню и маршрут появятся сами. Тексты статуса и подсказок раздела задаются
полем `texts`, отдельная страница вместо проверки и генерации — полем `page` (так сделана «Тестовая персона»).

Сгенерированные номера предназначены только для тестирования.

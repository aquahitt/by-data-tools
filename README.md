# by-data-tools

Валидация и генерация тестовых данных Республики Беларусь. Работает целиком в браузере:
введённые данные никуда не отправляются и не сохраняются.

**Открыть:** https://aquahitt.github.io/by-data-tools/

## Разделы

Разделы собраны в левом меню по категориям. Адрес раздела можно сохранить или отправить:
`#/personal-number`, `#/passport-number`, `#/unp`, формат — параметром `?format=`.

| Категория | Раздел | Статус |
|---|---|---|
| Документы | Идентификационный номер | готово |
| Документы | Номер паспорта | готово |
| Организации | УНП | готово |
| Финансы | IBAN / номер счёта | скоро |
| Контакты | Телефон | скоро |

## Идентификационный номер паспорта

Проверка, разбор и генерация (случайно или по заданным полям) в двух форматах —
формат выбирается переключателем:

- **2012+** — по [постановлению МВД РБ № 345 от 18.10.2011](https://mvd.gov.by/uploads/dgim/r345.pdf):
  `7xxxxxx A NNN PB C`, все правила обязательны.
- **До 2012** — пол и век, дата рождения, регион, порядковый номер, статус. Официально не описан;
  структура и коды — по данным [АиФ](https://aif.by/dontknows/kak_rasshifrovat_lichnyy_nomer_pasporta)
  и [onliner.by](https://forum.onliner.by/viewtopic.php?t=895870&start=160). Несовпадение контрольной
  цифры с формулой 7-3-1 показывается как предупреждение, а не ошибка.

Контрольная цифра: первые 13 символов, веса `7-3-1`, `A=10 … Z=35`, сумма по модулю 10.

## Номер паспорта

Серия (2 латинские буквы) и номер (7 цифр). Два формата:

- **Образца 1996 г.** — серия по органу выдачи (`AB`, `BM`, `HB`, `KH`, `MP`, `MC`, `KB`, `PP`, `SP`, `DP`);
  серия не из списка — предупреждение, а не ошибка.
- **Биометрический (с 2021)** — серии бланков официально не опубликованы
  ([постановление Совмина № 297](https://etalonline.by/document/?regnum=c22100297) задаёт только формат),
  принимается любая пара латинских букв; `DP` — дипломатический.

В разборе и при генерации показывается номер документа из машиночитаемой зоны с контрольной цифрой
(ICAO 9303, веса `7-3-1`).

## УНП

Учётный номер плательщика по [постановлению МНС № 127 от 31.12.2003](https://pravo.by/pdf/2004-38/2004-38(010-043).pdf)
(глава 3, приложения 2–3): 9 знаков — код области, порядковый номер, контрольная цифра
(веса `29 23 19 17 13 7 5 3`, остаток от деления на 11; остаток 10 — такой УНП не выдаётся). Два формата:

- **Организация** — девять цифр, первая `1`–`7` (область).
- **Физлицо / ИП** — буква области (`A B C E H K M`), буква вместо первой цифры порядкового номера
  (`0→A 1→B 2→C 3→E 4→H 5→K 6→M 7→O 8→P 9→T`), шесть цифр и контрольная цифра.

В примере постановления для физлица (`МА1953681`) сумма посчитана с ошибкой; инструмент следует формуле
(`MA1953684`), как и [python-stdnum](https://github.com/arthurdejong/python-stdnum/blob/master/stdnum/by/unp.py).
Префикс «УНП» при вводе допускается.

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173/by-data-tools/
npm test
npm run build
```

Новый раздел — модуль формата в `src/formats/` (реализует `FormatModule` из `src/core/types.ts`)
и запись в реестре `src/tools/index.ts`; меню и маршрут появятся сами.

Сгенерированные номера предназначены только для тестирования.
